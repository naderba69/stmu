# STMU — modern homepage concept

A responsive, bilingual (Arabic/French) homepage concept for the Société Tunisienne de Médecine d'Urgence. The interface is built with React and Vite, supports RTL/LTR layout, and is designed for mobile, tablet, and desktop screens.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```

## Project notes

- The landing page defaults to Arabic and includes a live Arabic/French language switch.
- Navigation, mobile menu, section links, and email/telephone contact links are functional.
- Official STMU links are used for the history, membership FAQ, conference resources, training article, and STMU Junior information.
- The 25th National Emergency Medicine Congress is shown as a 2026 archive, not as a future event.
- A dedicated “Coming up” callout introduces the next national congress; date and venue remain marked as pending official confirmation rather than being invented.
- The homepage is a front-end implementation. Membership and newsletter services remain on the official STMU site; no unconfigured backend or data submission is implied.
- `public/images/emergency-team.jpg` is original generated artwork created for this interface.
